# Changelog

## 0.2.0 - 2026-08-27

- Unified search highlights and next/previous navigation across Structure and Source views.
- Visible match and containing-branch indicators in the lazy Structure tree.
- Viewport-based syntax highlighting keeps color schemes active for files above 2 MB.
- Added `Ctrl+G` jump to a required line and optional character.
- Added an explicit, asynchronous GitHub release check to the About dialog.

## 0.1.0 - 2026-08-18

- Initial cross-platform structure viewer and source editor.
- Lazy folding, strict parsing, duplicate-key warnings and document statistics.
- Search, mark, word wrap, format, scalar editing and JSONPath copy.
- Pretty, minified and JSON Lines export.
- Complete dark/light UI, syntax palettes and per-user settings import/export.
